# Demo: bounded review of e3d-code resume/handoff (2026-11-08)

Setup: `e3d` (Pi 1.5.0) in `~/repos/e3d-code`, foreground `anthropic/claude-sonnet-5-5`, helper `openai/gpt-5.5`, Pilot (local stdio, 17 tools) and Brain (stdio, 8 tools) connected through Pi's MCP. Credentials loaded at launch by a wrapper outside the repo.

Task: find correctness/robustness problems in how `bin/e3d-code` resumes interrupted runs and hands off between phases. Nothing was edited, nothing was run.

| Part | Result |
|---|---|
| Brain | Searched; returned only an unrelated note. Foreground said so and cited none. |
| Foreground analysis | 6 findings (no real resume; dry run writes a success summary; stale summaries; handoff awk edge cases; failed summaries skipped; octal phase numbers, `swallowed || true`). |
| Helper, first run | Hit the 12-turn cap and returned nothing ($0.29 spent). **Defect found:** cap aborted instead of asking for a wrap-up. Fixed: steer at `max-2`, abort only past the cap. |
| Helper, second run | 3 findings, all quotes confirmed in the snapshot, $0.31. Two match the foreground's findings (dry-run summary treated as success; stale handoff preserved). |
| Verified by hand | Octal claim reproduced in bash (`(( 08 >= 3 ))` errors). Dry-run summary write confirmed at `bin/e3d-code:1534`. Others unverified. |
| Pilot | Connected, **not exercised** in this demo. |

Defects in E3D Loop found by using it live: Pi expands `~` in file tools (confinement hole, fixed + tested); timeout armed after setup; token backstop missing; snapshot cleanup gap; print mode hangs if stdin stays open (use `</dev/null` in scripts).

Cost: about $0.89 helper total across 3 runs plus Sonnet foreground (not measured here).

Not shown: any claim that the helper improved results versus a single model. This is one sample.

Filed upstream from this review (confirmed by reading the code): [e3d-code#3](https://github.com/spacepacket1/e3d-code/issues/3) (dry run writes a success summary) and [e3d-code#4](https://github.com/spacepacket1/e3d-code/issues/4) (leading-zero phase numbers). The other findings above were not filed: they are design observations or unverified.
