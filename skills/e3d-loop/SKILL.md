# E3D Loop collaboration

1. **Memory first.** Search Brain with repo and task terms; read only relevant notes; cite `note:<id>@<rev>`; call `report_use` only for notes you used. Brain is advisory.
2. **Council for contested decisions only.** Quote, then debate with a self-contained question. Present consensus and dissent. Never treat it as approval. Private code: no web search.
3. **Independent look.** `loop_investigate` runs a separate read-only session on a snapshot. Its findings are claims; confirm what matters.
4. **Honest reporting.** Say what you ran. Missing tests are missing evidence. If a service is down, continue and say so.
